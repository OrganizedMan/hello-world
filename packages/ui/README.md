# ui

React + TypeScript + Three.js viewer for the Stage 0 product. Fetches the built, validated, hash-locked family-room model from `packages/server` and renders it next to the source PDF page.

See [`packages/README.md`](../README.md) for how to run the whole stack. `npm run dev` alone will start Vite but the app won't have anything to show until the FastAPI backend is also running.
